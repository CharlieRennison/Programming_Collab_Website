How computing has affected navigation

All navigation from your phone to your sat nav is calculated using pathfinding algorithms.

The most common pathfinding algorithms consist of:

  • Dijkstra: This works by repeatedly selecting the nearest unvisited node and updating the estimated distance (cost) between each neighbouring nodes
  • A*: Similar to Dijkstra but it uses a heuristic. This is an estiamte of the remaining distance to the final destination. This is used to influence decision making when calcuting which node to travel to.
  • Depth First Search

What are pathfinding algorithms?

Pathfinding algorithms are methods used to find the most efficient route between two points in a graph or network.

  • Nodes: Represent individual items e.g junctions
  • Edges: Represent the roads
  • Weights: Represents the cost travelling between nodes e.g distance or time
